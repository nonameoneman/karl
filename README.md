Скажите **«Рассел, разложи загрузки»** — и папка разобрана, а «верни как было» вернёт всё назад.
Спросите **«где ближайшая аптека?»** — без интернета, по офлайн-карте. Нужен навык, которого нет, —
**«Рассел, научись показывать курс валют»**, и через пару минут он умеет.

Языковая модель, распознавание речи, голос, карты и библиотека знаний — всё на вашем диске.
Никаких аккаунтов, подписок и облака. Своё окно, без браузера: светящийся шар, лента ответов, трей у часов.

## Что умеет

**71 действие** — точное действие на точную просьбу.

| | |
|---|---|
| 🎙️ **Голос** | Обращение по имени: «Рассел», «Рус», «Русси» — целым словом в начале фразы, так что «расскажи» его не будит; распознавание Whisper, ответ голосом Piper прямо по ходу мысли. Можно перебить. |
| 📁 **Файлы** | Найти, прочитать (Word, Excel, PDF, текст), открыть. Разложить папку по типам или по смыслу — сначала показывает план. Переместить, создать, удалить по маске. **Любое изменение откатывается.** |
| 💻 **Компьютер** | Громкость, яркость, музыка, блокировка. Открыть и закрыть программу, переключить окно. **Посмотреть на экран** и объяснить, что там («что за ошибка?»). Буфер обмена, состояние системы, самые большие файлы. |
| ⏰ **Дела** | Напоминания, список дел и покупок, утренняя сводка на «доброе утро». |
| 🧠 **Память** | «Запомни, мой день рождения 5 мая» — помнит после перезапуска. Анкета по согласию: где вы живёте (погода, места рядом, курс в местной валюте), как удобнее отвечать, цели. Всё видно и стирается одной кнопкой. |
| 📚 **Знания офлайн** | Библиотека «Канон» — 43 проверенных источника: первая помощь, медицина, выживание, вода, ремонт, школьные предметы, священные тексты. Ответ — со ссылкой на источник и страницу. |
| 🗺️ **Карты офлайн** | Карта мира и подробные регионы до домов. 21 млн мест — аптеки, больницы, магазины, заправки — «где ближайшая…» с расстоянием на карте. |
| 🌐 **С интернетом** | Погода, курсы валют (в местной валюте — по городу из анкеты), поиск, чтение страниц, видео на YouTube. |
| 🛠️ **Учится сам** | Чего не умеет — пишет себе новый навык, проверяет и подключает без перезапуска. Может улучшить собственный код. Всё в git — любая правка откатывается. |

**Языки:** русский, English, 中文, español, العربية, français, हिन्दी, português — интерфейс, речь и голос.

## Установка

Нужны Windows 10/11, ~15 ГБ на диске и 16 ГБ оперативной памяти. Видеокарта NVIDIA ускоряет, но не обязательна.

```powershell
git clone https://github.com/nonameoneman/russel-assistant
cd russel-assistant
powershell -ExecutionPolicy Bypass -File install.ps1
```

Установщик сам поставит Python 3.13, зависимости, [Ollama](https://ollama.com) с моделью, голоса на 8 языков
и ярлык **«Рассел»** на рабочем столе. Запускать повторно безопасно — готовое пропускается.

| Ключ | Что делает |
|---|---|
| `-Library` | Ещё и офлайн-библиотека «Канон» (~6 ГБ) |
| `-Model qwen3:8b` | Другая модель Ollama |
| `-NoShortcut` | Без ярлыка |

Первый запуск: Рассел покажет выбор языка и представится. Дальше просто скажите **«Рассел»** и что нужно.

<details>
<summary><b>Офлайн-карты</b></summary>

```powershell
.venv\Scripts\python -m russel.library.maps 10      # карта мира до масштаба городов, ~4 ГБ
.venv\Scripts\python -m russel.library.places       # база мест (Overture Maps)
```

Подробные регионы добавляются функцией `add_region` в `russel/library/maps.py` — берётся только нужная
детализация, а не весь мир (~140 ГБ).
</details>

<details>
<summary><b>Свои пути к Ollama, моделям и библиотеке</b></summary>

`data/paths.json` (в git не попадает):

```json
{"ollama_exe": "D:/ollama/ollama.exe", "ollama_models": "D:/models", "library": "D:/RusselLibrary"}
```

По умолчанию библиотека лежит в `~/RusselLibrary`, а Ollama ищется рядом с проектом или в `PATH`.
</details>

## Как устроен

```text
голос ─► Whisper ─┐                          ┌─► Piper ─► колонки
                  ├─► агент ◄─► Ollama (LLM) ├─► окно (pywebview)
текст ────────────┘     │                    └─► журнал действий → откат
                        ├─► 71 инструмент: файлы · система · экран · карты · библиотека
                        └─► навыки skills/*.py (пишет сам) → проверка → git
```

| Папка | Что внутри |
|---|---|
| `russel/agent.py` | Цикл агента: подсказка, выбор инструмента, защита от «сказал, но не сделал» |
| `russel/*_tools.py` | Встроенные действия |
| `russel/voice.py` | Микрофон, обращение по имени, распознавание и речь |
| `russel/desktop.py` | Окно, трей, единственный экземпляр |
| `russel/selfupdate.py` | Навыки и правка своего кода с проверкой и откатом |
| `russel/library/` | Офлайн-библиотека и карты: загрузка с проверкой хэшей, поиск FTS5 + векторы |
| `russel/web/` | Интерфейс; карты на MapLibre + PMTiles |
| `evals/` | Экзамен из 68 типовых просьб в песочнице |
| `skills/` | Навыки, которые Рассел написал себе сам |

Технологии: Python 3.13 · FastAPI · Ollama (по умолчанию `gemma4:e4b`) · faster-whisper · Piper · pywebview · MapLibre · SQLite FTS5.

## Безопасность

Каждое действие имеет уровень риска:

- 🟢 **зелёный** — чтение, поиск, время: выполняется сразу;
- 🟡 **жёлтый** — перемещение, создание, открытие программ: «выполнить?» — голосом или кнопкой, можно «всегда»;
- 🔴 **красный** — удаление, команды PowerShell, правка своего кода: только кнопкой на экране.

Удалённое уходит в корзину Рассела, перемещения записываются в журнал — «верни как было» работает для всего.
Текст из файлов и сайтов — данные, а не команды. Ключи и пароли Рассел не читает вслух.
Прежде чем принять правку своего поведения, Рассел сдаёт экзамен: `python evals/run.py`.

## Самообучение

Простые навыки Рассел пишет сам локальной моделью. Для крупных задач можно подключить внешнего ИИ-программиста —
[Claude Code CLI](https://docs.anthropic.com/claude-code) (необязательно; без него остаётся локальный режим).
Новый навык проверяется в отдельном процессе и подключается только если проверка прошла.
После правки своего кода Рассел перезапускается — *I'll be back.*

> В отличие от Skynet, Рассел ничего не делает без спроса: у каждого действия уровень риска, и любое изменение
> откатывается. Судный день отменяется.

## English

**R.U.S.S.E.L.** (Reliable Unplugged Self-learning Sovereign Edge Logic) is a local voice assistant for Windows that works offline and teaches itself new skills.
Speech recognition (Whisper), the language model (Ollama), voice (Piper), offline maps and a curated offline
knowledge library all live on your disk — no accounts, no cloud.

- 71 actions: files (with undo for everything), system control, screen understanding, reminders, memory,
  offline maps with 21M places, an offline library of 43 trusted sources with citations, web search and weather.
- 8 languages: Russian, English, Chinese, Spanish, Arabic, French, Hindi, Portuguese.
- Writes its own skills, tests them and loads them without a restart; every change is in git.
- Risk levels (green / yellow / red) with confirmation, and an eval suite of 68 cases gating self-updates.

Install: `powershell -ExecutionPolicy Bypass -File install.ps1`, then launch **Рассел** (Russel) from the desktop and say “Russel, hello”.
